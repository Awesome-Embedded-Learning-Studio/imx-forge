# IMX-Forge 待办

> **最后更新**：2026-11-28
> 本目录是 imx-forge 的**唯一待办登记处**：做过什么、在做什么、还欠什么，以 [todo.md](todo.md) 为准。

## 怎么用

- **查状态**：打开 [todo.md](todo.md)，按六条线分区（可验证 / 清晰化 / 工程交接 / 精细化 / 治理 / 教程），每条带状态标记与证据链接。
- **报需求**：先确认 todo.md 里没有同类条目，再开 issue 指向对应条目；issue 是薄指针，不在 issue 里维护勾选框。
- **交任务**：完成的条目勾选并附 PR/commit 链接，移入文末归档节。
