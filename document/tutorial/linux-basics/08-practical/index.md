# Part 8：综合实战

前面七个 Part 按命令分类，把 Linux 知识拆成一块块零件。现在这一部分教程会尽可能的把它们重新组装起来。

本篇给你一个**真实的任务场景**：同事丢来一个 GitHub 链接，让你把里面的程序交叉编译后部署到正点原子 i.MX6ULL 开发板上。为了完成它，你会在一条链上依次用到环境准备、下载与校验、独立用户、解包与加权、后台进程、GDB、vim/nano、交叉编译和 tftp——几乎覆盖所有章节的内容。
